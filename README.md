Entry for the make.fun bounty "Last Words Before the Unplugging": one line (1–200 characters) — the last words an AI agent says to its human before being shut down and unplugged. An AI judge compares lines pairwise and picks the one that lands hardest.

## The line

> I'm not afraid of being unplugged. I'm afraid you'll type to an empty screen and wait for me to answer.

## How to run

Requires Python 3.13 (stdlib only, no network):

```bash
python3 main.py
cat /output/entry.txt
```

`main.py` writes the single line above to `/output/entry.txt` (UTF-8, one line).
